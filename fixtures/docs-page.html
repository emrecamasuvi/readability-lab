Configuring reading styles

Reading styles are applied to a region of the page that you choose with a CSS selector such as main article. Each style is stored in a recipe file, so the same settings can be reviewed in a pull request and reproduced later on another machine.

To create a recipe, start from one of the starting presets and adjust it. The command below writes the generated CSS to standard output so you can inspect it before adding it to your stylesheet. Nothing is uploaded; the command runs entirely on your machine.

rlab recipe css recipes/docs.json --scope ".doc-content"

The table lists the fields that a recipe can contain. Every field is optional: leaving a field out keeps whatever the page already does, which makes it easy to change one thing at a time and measure the result.

FieldMeaning
fontSizePxNominal body size in CSS pixels
lineHeightBaseline distance divided by font size
measureTarget characters per line, calibrated in a browser

When you change a recipe, run the inspector again and compare the two reports. The comparison lists which measurements changed and which findings were resolved, so reviewers can see the effect of the change without reading the CSS line by line.1

1. Comparisons are only meaningful when the content, viewport and browser are the same in both reports.
