The publisher sets a recipe; the reader still decides

This page ships a publisher recipe: 17px text, about 68 characters per line, and 1.45 line spacing. The settings panel beside it uses the same portable profile format as the Readability Lab browser extension and workbench, so a reader's choices travel with them.

Any setting you change wins over the publisher's recipe. If you mark a setting as something to keep, picking a starting point later will not overwrite it. Your settings are stored on this device only, and the share code contains settings but never the text you read.

Try the controls with only a keyboard: Tab moves between controls, arrow keys move sliders and radio buttons, and Space toggles checkboxes. Then enlarge the page text in your browser; the panel wraps instead of clipping.

Turning off "Use my reading settings" shows the original page so you can compare. Reset returns to the publisher's recipe.
