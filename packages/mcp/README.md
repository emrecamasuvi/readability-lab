# @emrecamasuvi/readability-lab-mcp

Stdio MCP server. Tools: `rl_inspect`, `rl_check`, `rl_compare`, `rl_claims`, `rl_claim`, `rl_recipe`, `rl_rules`. Everything runs locally with Playwright.

```sh
node packages/mcp/bin/readability-lab-mcp.mjs
# Claude Code:
claude mcp add readability-lab -- node /abs/path/packages/mcp/bin/readability-lab-mcp.mjs
```

Use it with the skill in `skills/readability-lab/SKILL.md`.
